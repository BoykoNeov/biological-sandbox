The cold first load

The one measurement that could still have overturned the browser decision, and the one both earlier slices skipped. They timed a warm load from a local server on a desktop and said plainly that neither number transfers.

What is measured here is time to a usable page at a known byte rate — the server paces its writes, and the page reports every byte that crossed, including the ones the worker fetched on its own thread and that the page's own resource timeline cannot see.

WHAT THIS IS NOT a real network

A paced local server models the throughput term of a slow link and nothing else. There is no latency, no TCP slow start, no packet loss, no CDN, no mobile radio. A real 5 Mbit/s connection is worse than this number, not better, and how much worse is not established here.
